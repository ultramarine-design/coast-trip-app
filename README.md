# 전국 해안 일주 앱 (PWA)

2026년 10월 2일~9일, 7박 8일 전국 해안 일주를 일자별로 펼쳐 보는 모바일 웹 앱이다.
아이폰 사파리에서 주소를 열고 공유 → 홈 화면에 추가하면 앱처럼 쓴다.
구조는 지리산 둘레길 앱(claude cowork/지리산-둘레길-앱)을 따랐다.

## 화면

1. 홈: 8일 카드 목록, 해역 칩(남해안·서해안·내륙·동해안). 출발 전에는 D-day와 남은 예약, 여행 중에는 오늘 일정 바로가기.
2. 일자 상세: 거리·주행·잘 곳·일출일몰, 시간표(장소마다 네이버 지도 버튼), 잘 곳(전화·예약·지도), 충전, 주의, 이전·다음 날.
3. 체크리스트: 예약, 전화 확인, 준비물. 체크는 기기(localStorage)에만 저장.
4. 부록: 충전, 차박 요령, 날씨, 줄이는 법, 연락처, 출처와 확인 범위.

## 데이터

모든 내용은 data/trip.json 하나에 있다. 빌드 단계 없음.
- 거리·주행 시간: OSRM 공개 경로 계산(정체 미반영).
- 일출·일몰: 천문 공식 계산치(오차 1~3분), KASI 공식값 아님.
- 운영시간·요금: 2026-10-01 웹 확인. 출처와 확인 수준은 trip.json sources에 있다.

## 고칠 때

1. data/trip.json 수정.
2. sw.js의 SHELL 버전을 올린다(coast-shell-v1 → v2).
3. 커밋, 푸시. GitHub Pages가 같은 주소에 반영한다.
